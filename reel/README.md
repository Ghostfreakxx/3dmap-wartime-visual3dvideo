# Election Season POV

A 35-second vertical satire reel (1080×1920, 30 fps) about young voters in
Mizoram being unimpressed by party politics. The finished file is
[`mizo-youth-reel.mp4`](mizo-youth-reel.mp4).

It is satire, and labelled as such on every frame. No real party or person is
named or depicted; the jokes are aimed at "every party". The numbers on screen
(promises counted, pothole days, the trust chart) are jokes, not data.

All drawings, text and sound are original and generated by the files here; no
existing meme images, songs or sound effects are used.

## Rebuilding it

Needs Node.js with Playwright, Python 3 with NumPy, and ffmpeg.

```bash
python3 audio.py
node render.mjs
```

Edit the text in `index.html`. Each scene is a `<div class="scene">` with its
start and end time in `data-a` and `data-b`; each element's `--d` is the second
it appears. To preview, serve this folder and open `index.html?play`.
