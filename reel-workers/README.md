# Party Worker POV

A 45-second vertical satire reel (1080×1920, 30 fps) about party workers trying
to stay relevant between elections. The finished file is
[`party-worker-reel.mp4`](party-worker-reel.mp4). It is signed "anonymous".

No real party or person is named. Three of the "manifesto auction" bids
(₹5 lakh for everyone, ₹15 lakh insurance, a gas cylinder at ₹750) echo real
promises from the 2023 Mizoram election manifestos, and the "80% fulfilled"
and "unfulfilled promises" scenes echo real claims parties have made about
each other. Everything else, including every number, is a joke.

All drawings, text and sound are original and generated by the files here.

## Rebuilding it

```bash
python3 audio.py
node render.mjs
```

Edit the text in `index.html`; each scene's start and end time is in `data-a`
and `data-b`, and each element's `--d` is the second it appears.
